# 导演与验收规范

## 导演方案模板

以单一观众目标组织内容。每镜回答“发生了什么、观众读到什么、下一镜为何出现”。分别写 2–3 个简短结构候选并推荐一个；用户已给结构时直接沿用。

分镜表字段：shot id、start/end frame、时间、单一信息/事件、完整文字与来源、构图/层级、主体/次主体轨迹、预备/冲击/回稳、相机及其理由、光/材质变化、声音 cue、转场来源与落点、完整可读保持区间、预览检查帧。

对每个 signature shot 写清形状如何演变、注意力如何延续。例：选中的消息气泡扩展为分析面板，关键词形成回复卡片；根据真实内容设计，不强制所有作品使用该例。

统一 DESIGN：颜色 token 及用途、最多两套主要文字层级系统、材质/光源、留白/对齐、主体比例、安全区、运动速度/缓动/弹簧和禁用项。品牌黑紫可以保留，但不是整片默认霓虹渐变。竖屏按真实发布平台和字幕区验证，不仅横屏裁切。

## 运动与空间

1. 一个主事件领导注意力；次层有响应、延迟、幅度差异，不能全部共用一个进度。
2. 物理因果：速度变化、接触、挤压、回弹要有一致理由；刚性物体不能像橡胶，轻物体不能像巨石。
3. 动作衔接维护位置/速度连续。预计算物理轨迹需固定步长和初态，随机访问不能依赖上一渲染帧。
4. 平面、2.5D 和真实 3D 都有相机/空间层次；用统一 world→screen 变换，标签、光圈和聚焦点跟随同一对象。
5. 光线和反射跟随实际形变、视角或光源；不要为了“活”而无故闪烁。接触影保持接触合理，不机械延迟所有阴影。
6. 转场源自形状、视线、运动或语义；设计遮挡和边界帧，避免空白。结构性硬切可以使用，通用淡入不是默认方案。
7. 不强制匀速一律禁止：传送带/扫描可匀速；有重量的入场与回稳采用适合的缓动/弹簧。
8. 活力包含停顿。阅读区不应被持续镜头抖动、粒子和装饰抢走注意。

## 阅读与真实信息

核心信息完整出现后保持至少 2.5 秒；较长中文句建议按字数/约4–5字每秒加理解余量估算，然后看样片校正。这是设计参考，不是语言定律。打字时间不计入完整阅读停留。时间不足时删字/分镜/延长，不默认高速闪过。

字幕使用实际配音片段时间；字幕、标题和界面聊天三者不同，不能把所有字幕强制延长导致重叠。密集聊天屏逐条引导，避免一次出现多段长回复。不编造用户产品数据、用户评价、功能或对话结果；示例数据和演示性界面在需要避免误解时标明。

## 时间轴与声音

只维护一份 frame/cue 数据，声音和字幕从它导出。每秒帧率 fps、BPM、起拍 offset 明确；恒定 BPM 时每拍帧数=fps*60/BPM，非整数按各 cue 的绝对时刻取整，不能逐拍累加舍入造成漂移。

音乐主导：先测真实音轨节拍和段落，不假设上传音乐就是120 BPM。旁白主导：先定脚本/声音时长/语义停顿，再选音乐和图形节奏；不得硬卡音乐破坏语义。关键接触 SFX 对齐实际接触帧，前导/尾音可错开；并非每个切换都要 whoosh。

优先使用用户音轨或代码合成选择。程序合成音频检查 NaN、削波、爆音、低频堆积；分层 music/voice/sfx，旁白可懂度优先。平台目标未另指定时可提议约 -14 LUFS、true peak 不高于 -1 dBTP，并按真实内容校验；不是所有片子一律同响度。无声片无需制造音轨。

TTS 整段优先；发音、数字、术语核对，ASR 是辅助证据而非真值，不因误识别篡改正确脚本。能听则试听，不能听时不能自称“声音自然且无问题”。

## 检查层级

### 环境烟测

实际启动浏览器→字体就绪→渲染当前路线测试帧→确认像素不是空白→短片编码→ffprobe。WebGL 要测试实际目标 shader，而不是只调用 getContext。记录实际耗时估算全片，不能沿用上游作者机器速度。

### 视觉证明

三张真实代码关键帧 + 3–5秒关键运动片段。人物额外核对模型表、表情/四肢/手持物连续；同一角色不每镜换脸。逐步模式中方案同意不等于视觉同意；一键模式由 agent 内部检查并修复，沿用全流程 delegated 记录，不等待用户看样片。遵循 SKILL.md 的确认记录。

### 逐镜检查

每镜起中末三帧、最大信息密度帧、所有转场边界前后至少两帧；复杂运动用0.1–0.2秒帧条并看连续片段。检查字形、溢出、碰撞、遮挡、空白、画面密度、相机路径、动作弹性/重量和读完时间。检查每个问题时留时间戳及修复记录。

### 编码后检查

- ffprobe：输出尺寸/fps/时长/帧数、编码/像素格式、音轨与声道。
- 预期与实际帧数一致；音画长度差解释清楚。
- ffmpeg blackdetect/freezedetect 仅标可疑区间，黑背景或有意停顿不能直接判失败。
- 音频 ebur128/astats 等客观检查加试听（可用时）；语音、字幕、动作 cue 对齐。
- 全速看完整片一次，检查前后连续性、阅读、声音与收尾。
- 不能只展示“评分95分”代替证据；无法核验部分明确写待验证。

## 交付契约

实际 MP4、封面/关键帧拼图、按需 SRT、源工程/依赖锁/重建命令、DIRECTOR/DESIGN、CREDITS 与 QA 记录。依赖不能指向 agent 会话临时目录；素材自包含或记录可合法重取地址。外部品牌和模板原作署名不要误进入成片，必要许可放工程 credits。只做技能创建时不替用户开始一支未经确定需求的视频。
